Defensive Programming Course Project 

Description: The purpose of the program is to create a ticket purchasing program that allows for users to log in, purchase tickets, keep records of tickets purchased, and keep information about the user. Written in Python and  use a client-server configuration. It should run  in the SEED Ubuntu machine we use for class. Data for the users  kept on the server either in a SQLite database. 
The client program  request the data from the server. At least 2 vulnerabilities are left in the program.  

Deliverables:

All program code with documentation (client and server code and any additional files used).
User guide with clear descriptions of how to run and navigate the program.
Documentation of (intentional) vulnerabilities left out in the program.
